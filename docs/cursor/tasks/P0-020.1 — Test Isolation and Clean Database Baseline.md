## 1. Fix backend test isolation first

Determine why repeated backend test runs inserted fixture users into the configured development PostgreSQL database.

Correct the test infrastructure so that:

- Tests never use the normal `DATABASE_URL`.
- Tests use an explicit isolated `TEST_DATABASE_URL` or a disposable compatible test database.
- There is no fallback from the test database to the development database.
- Fail immediately if:
  - `TEST_DATABASE_URL` equals `DATABASE_URL`.
  - A test attempts to use a non-test database.
  - Test environment configuration is missing.
- Override every FastAPI/SQLAlchemy database dependency and direct service session.
- Use deterministic cleanup/rollback.
- Generate unique fixture identifiers where individual tests require separate users.
- Running the complete backend suite must not change development-database row counts.

Add a regression guard proving that tests cannot connect to the configured development database.

## 2. Institutional identifier constraints

Create a follow-up Alembic migration after P0-020.

Enforce:

- Student `roll_number` is required and cannot be blank.
- Faculty `employee_code` is required and cannot be blank.
- Roll numbers are globally unique after trimming and case normalization.
- Employee codes are globally unique after trimming and case normalization.
- Student roll numbers are stored trimmed and uppercase.
- Faculty employee codes are stored trimmed and uppercase.
- Public/API/import validation returns a clear duplicate-record error.
- Admin and Super Admin remain compatible without requiring student/faculty identifiers.

Use database-level uniqueness equivalent to:

- `upper(btrim(roll_number))`
- `upper(btrim(employee_code))`

Replace the weaker P0-020 indexes safely if necessary.

Add tests for:

- Exact duplicate
- Case-only duplicate
- Leading/trailing-space duplicate
- Concurrent duplicate creation
- Blank identifier
- Student without roll number
- Faculty without employee code
- Valid distinct identifiers
- Duplicate rows inside one master-upload batch
- Duplicate against an existing database record

Do not silently rename or merge identifiers.
